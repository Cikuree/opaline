# Classroom Run

Mode hardcore coopératif Minecraft (Fabric, 26.3) pour ~4 joueurs : une barre de vie partagée, une mort collective, et chaque run recommence dans un nouveau monde, au départ d'une salle de classe.

- `src/` : mod Fabric `classroomrun` (serveur + client)
- `structure/` : générateur Python de la salle de classe
- `pack/` : manifeste packwiz
- `launcher/` : launcher Rust
- `CONTRACT.md` : contrat réseau serveur → client
- `TESTING.md` : checklist de test en jeu
